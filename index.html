📖 ¿Cómo jugar?▾
01
Host configura
Ajusta tiempo por turno, cartas por jugador, duración de partida y nombre del sprint. Edita el mazo de cartas.
02
Todos se unen
Cada persona entra con el link o código. Mínimo 2 jugadores. La sala se cierra al iniciar.
03
Roba y responde
El jugador activo roba carta, escribe su respuesta y presiona ✅ Enviar. Responder = -1 carta.
04
El equipo reacciona
Los demás reaccionan con 👍 👎 🔥 💡 ❤️. Luego el jugador presiona ➡ Pasar turno.
05
Cartas Wild
ROBA 2 = siguiente responde 2 seguidas. ROBA 4 = 4 jugadores reciben +1 carta. SALTA habilita el botón Skip. REVERSA habilita el botón Reversa. WILD COLOR = el activo elige la siguiente categoría.
06
Tiempo para reaccionar
Al enviar la respuesta, el equipo tiene unos segundos (configurable) para reaccionar. El turno avanza solo al terminar ese tiempo.
06
¡RETRO UNO!
Con 1 carta tienes 10 segundos para gritar ¡RETRO UNO! Si otro te atrapa primero = +2 cartas de penalización.
07
Cómo ganar
Llega a 0 cartas primero = ganas al instante. Si termina el tiempo o el host finaliza = gana quien tenga menos cartas.
08
Pausa y control
El host puede pausar el juego, terminar la partida manualmente, o reiniciar una nueva retro.
Las cartas
🏆 AZUL — LogroAlgo positivo del sprint. Responder = -1 carta.
🚧 ROJO — RetoProblema o blocker. Responder = -1 carta.
💡 VERDE — IdeaExperimento o mejora. Responder = -1 carta.
✅ AMARILLO — AcciónCompromiso concreto. Responder = -1 carta.
🌈 WILD — ComodínEfectos especiales sobre otros jugadores.
Wild — efectos en cartas: ROBA 2 = siguiente responde 2 preguntas seguidas · ROBA 4 = los 4 siguientes reciben +1 carta · SALTA = pierde turno · WILD COLOR = elige categoría para el siguiente · REVERSA = invierte orden · RETRO UNO no gritado a tiempo = +2 cartas de penalización.
